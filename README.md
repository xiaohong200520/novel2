# 我与诡异有个约会

> 他们说我走进去的那条巷子，出不来。
> 可没人告诉我，出不来是件这么好的事。

**类型**：恐怖 / 恋爱 / 都市怪谈
**篇幅**：五卷 100 章，目标 20 万字
**当前进度**：12 / 100 章（约 2.4 万字）

---

## 简介

沈迟二十六岁，在深圳改了三年的方案。祖母去世一个月后，他才回到江市西边的打铜巷，处理那间叫「留白」的照相馆。

店里的橱窗摆着七张婚纱照。所有的脸都被刮掉了。

三楼有一间暗房，桌上放着三张洗完了却全白的相纸。第一天夜里，那台老式双反相机自己响了一声。

照片洗出来，画面里的他面朝镜头。

可他当时，是背对着镜头的。

而在照片上，他身后站着三个没有脸的女人。

---

## 设定一句话

> 诡异没有实体，只有被人**认真地看过**，才能存在。
> 所以它们约人。
> 约的代价，是摄影师自己。

## 三位女主

| | 名字 | 本质 | 异能 | 代价 |
|---|---|---|---|---|
| 红 | **苏绾** | 连结 | 缝——缝合伤口、衣扣、误会，也能缝死一个人的嘴 | 每约一次，抽走一根连着他的线 |
| 镜 | **白露** | 映照 | 映——住在任何反光面上，可以完整复制一个人 | 要人陪。每别一次，他被人认出的感觉就淡一分 |
| 纸 | **阿箬** | 形体 | 烧与食梦——烧掉噩梦、记忆、约定 | 吃梦。吃到最后，人变一张纸 |

她们原本是同一个东西。七十年前被拆成了三份。

## 写作约定

- 每章一个钩子，恐怖与温柔交替推进。
- 亲密戏一律停在门外，张力留在"没有发生"的那部分。
- 每失去一样东西，都要写清是谁忘了他、忘的是哪件事。
